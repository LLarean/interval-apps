# Tabata Timer

A simple Tabata interval timer: a countdown, then rounds of work and rest,
ending on the last work interval.

| Setting | Default | Range |
|---|---|---|
| Rounds | 8 | 2–99 |
| Work | 20 s | 10–999 s |
| Rest (also the countdown) | 10 s | 5–999 s |

Android application id: `com.LLarean.TabataTimer`, the same as the Unity
version, so store listings update in place.

```sh
flutter run
```
