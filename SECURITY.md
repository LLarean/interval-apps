# Security policy

The apps have no accounts, servers or network features: they keep their
settings and your music on the device. Security issues are still possible —
in the Android configuration, the CI pipeline or a dependency.

## Reporting a vulnerability

Please report it privately through
[GitHub's private vulnerability reporting](https://github.com/manul-wizard/interval-apps/security/advisories/new)
rather than in a public issue. You will get an answer within a week.

Only the latest version on `main` and the latest store releases are supported.
